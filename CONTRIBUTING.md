# Contributing

Read `AGENTS.md`, the canonical CyberSecGPT doctrine, `docs/ARCHITECTURE.md`,
and `SECURITY.md` before changing this repository.

Every proposed source requires primary-source rights evidence and explicit
decisions for acquisition, processing, training, derived statistics, and
artifact distribution. Do not commit corpus bytes, credentials, personal data,
quarantined data, or generated build output.

Architecture/security/licence gates precede implementation. Changes require
focused tests, the complete supported validation matrix, exact distribution
verification, final diff and security review, exact-head owner acceptance, and
post-merge verification.
